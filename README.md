PROJECT DESCRIPTION
Marketing Funnel & Conversion Performance Analysis Dashboard
Project Overview

This project analyzes marketing funnel performance and customer conversion behavior using the Bank Marketing Dataset.

The goal of the analysis was to identify:

Funnel drop-off points
High-performing customer segments
Effective contact methods
Campaign efficiency trends
Opportunities to improve conversion performance

The dashboard was developed using Microsoft Power BI.

Business Problem

Marketing and sales teams often struggle to understand:

Why customers fail to convert
Which customer segments generate the best results
Which campaign strategies are effective
Where the largest funnel drop-offs occur

This project addresses these challenges through interactive business intelligence reporting and conversion analytics.

Key Insights
Overall conversion rate was approximately 12%
Cellular outreach generated the highest conversion rates
Students and retired customers converted most effectively
Previous successful campaign outcomes significantly increased conversion likelihood
Excessive repeat contact attempts reduced conversion performance
Business Recommendations

✔ Prioritize high-converting customer segments
✔ Focus on cellular outreach campaigns
✔ Reduce excessive repeat contacts
✔ Retarget customers with previous successful outcomes
✔ Optimize campaign timing using monthly performance trends
